# Прогулка с сыном: от Аптекарского огорода до сада Баумана

Два сайта в одной папке.

**`ar.html` — «Оживи Москву».** Десять кнопок, десять анимаций поверх камеры. Нажал кнопку,
навёл камеру куда написано — и на пустом месте вырастает Сухарева башня, поднимаются
Красные Ворота, едут кабинки патерностера. Геолокация не нужна, работает где угодно.

**`index.html` — квест с картой.** Маршрут, точки, истории, вопросы, значки и диплом.
Геолокация сама открывает историю, когда подходишь к месту.

## Что нужно для сцен

- **Камера.** Браузер спросит разрешение. Если не дать — анимация всё равно покажется, только на градиенте вместо улицы.
- **HTTPS.** На GitHub Pages он есть. По обычному http камера не включится.
- **Звук.** У каждой сцены свой: колокол, фанфары, цокот копыт, треск льда, залпы салюта. Всё синтезируется на лету, файлов нет. Выключается кнопкой в углу.
- **Наклон телефона** двигает слои с разной скоростью — получается глубина.

## Эффекты

Что происходит с каждой фотореконструкцией:

- **Проявление.** Объект печатается снизу вверх, по кромке идёт световая линия, потом наводится резкость.
- **Дыхание кадра.** Медленный зум и сдвиг, плюс лёгкое покачивание, будто снимают с рук.
- **Свет по силуэту.** Свечение, блик и сумеречная тонировка накладываются через маску по альфа-каналу картинки, поэтому не вылезают за края здания.
- **Лучи** в воздухе за объектом и мягкая тень под ним.
- **Сезоны и время суток** — фильтрами: осень, зима, весна, сумерки, сепия.
- **Распад в финале.** Объект разваливается на четыре полосы, они разлетаются и растворяются.
- **Выноски** с пульсирующей точкой появляются по таймингу и гаснут к концу.
- **Частицы** на canvas: пыль, снег, изморозь, капли, искры, угли, пыльца, листья, ноты, туман, звёзды, салют.

Кнопка «Ещё раз» перезапускает сцену с начала.

## Квест с картой

- Маршрут фиолетовым пунктиром, метки точек, синяя точка «мы здесь», зелёный след пройденного.
- Подошли ближе 60–90 метров — телефон звякнул, история открылась сама.
- Компас в кружке показывает, куда идти. Включается по нажатию (на iPhone иначе нельзя).
- В каждой точке история на три-четыре абзаца, факт и вопрос на три варианта.
- Кнопка с динамиком читает историю вслух.
- За точку — значок, в конце диплом с именем ребёнка.
- В настройках есть «Тренировка дома»: точка едет по маршруту сама, чтобы проверить всё до выхода.

## Как запустить

```bash
npx http-server -p 8099 .
```

### GitHub Pages

Settings → Pages → Deploy from a branch → ветка `claude/interactive-route-ar-site-bmvlvc`, папка `/ (root)`.
Сцены будут на `https://crucian1812-a11y.github.io/MAP/ar.html`, квест — на `.../MAP/`.

## Файлы

```
ar.html             галерея сцен и сама сцена
index.html          квест с картой
css/ar.css          вёрстка галереи и все анимации сцен
css/style.css       вёрстка квеста
js/ar-scenes.js     десять сцен: слои SVG, титры, звук  ← сюда лезть за содержанием
js/ar-particles.js  частицы на canvas: пыль, снег, искры, салют, туман, пыльца
js/ar-engine.js     камера, слои с параллаксом, титры, синтез звука
js/data.js          маршрут и тексты квеста
js/geo.js           расстояния, азимуты, геолокация, компас
js/map.js           Leaflet: маршрут, метки, наша позиция
js/app.js           логика квеста
sw.js               офлайн-кэш
```

Из внешнего — только Leaflet и тайлы OpenStreetMap для карты квеста. Сцены не тянут ничего:
вся графика нарисована в SVG прямо в коде, звук синтезируется в браузере.

## Картинки

Исходники лежат в `assets/new/`, готовые вырезки — в `assets/*.webp`. Обработка не ручная:
скрипт снимает фон (белый, нарисованные клетки «прозрачности» или небо), убирает клетки,
запертые внутри объекта, растушёвывает кромку, обрезает поля и жмёт в WebP. Все девять
файлов вместе весят около трёх мегабайт.

Если добавляете новую локацию: картинка без интерфейса и подписей, объект целиком,
вертикальный или квадратный кадр, фон любой — лишь бы однородный.

## Координаты

Точки маршрута расставлены вручную по карте, без геокодера — метка может стоять
в двадцати-тридцати метрах от нужного дома. Чинится на месте: настройки квеста → «Калибровка точек» →
перетащить метку → скопировать координаты в `js/data.js`.
