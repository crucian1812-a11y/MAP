# Озвучка

Тут лежат голосовые дорожки. Имя файла — `<что читаем>--<голос>.mp3`:

- `point-suharev--ru_RU-dmitri-medium.mp3` — история точки квеста
- `scene-suharev--ru_RU-dmitri-medium.mp3` — рассказ к AR-сцене

`manifest.json` собирается скриптом и говорит сайту, какие голоса есть.
Пока файлов нет, сайт читает системным голосом телефона.

## Сгенерировать

Actions → «Озвучить прогулку» → Run workflow. Голоса Piper:
`ru_RU-dmitri-medium` (мужской, спокойный), `ru_RU-denis-medium`,
`ru_RU-ruslan-medium`, `ru_RU-irina-medium` (женский). Можно указать несколько
через запятую — тогда в настройках сайта появится выбор.

Тексты берутся прямо из данных сайта, руками их писать не нужно:
`node scripts/build-voice-scripts.js` кладёт их в `audio/scripts/`.

## Записать своим голосом

Читать может и папа. Сложите mp3 с именами `point-<id>--papa.mp3`
и `scene-<id>--papa.mp3`, потом запустите тот же воркфлоу с галочкой
«только пересобрать список голосов». В настройках появится голос «papa».

Список `<id>` — имена файлов в `audio/scripts/` без расширения.
