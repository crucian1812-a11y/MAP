# Прогулка-квест: от Аптекарского огорода до сада Баумана

Сайт для прогулки с ребёнком по маршруту **проспект Мира, 39с1 → сад имени Н. Э. Баумана**.
Телефон следит за геолокацией, у каждой точки сам открывает историю, задаёт вопрос и
показывает поверх камеры то, чего на этом месте давно нет: Сухареву башню, Красные Ворота,
карету перед больницей Шереметева.

Одиннадцать точек, примерно 3,5 км, два-три часа с остановками.

## Что внутри

- **Карта** — маршрут фиолетовым пунктиром, метки точек, синяя точка «мы здесь», зелёный след пройденного.
- **Геотриггеры** — подошли ближе 60–90 метров, телефон звякнул, история открылась сама.
- **Компас** — стрелка в кружке показывает, куда идти. Включается по нажатию на кружок (на iPhone иначе нельзя).
- **«Горячо — холодно»** — подсказка на карточке, ребёнку понятнее, чем метры.
- **Истории** — по три-четыре абзаца простым языком, с фактом и вопросом на три варианта.
- **Чтение вслух** — кнопка с динамиком в шапке, голос браузера читает по-русски.
- **Дополненная реальность** — камера плюс компас: десять сцен привязано к сторонам света, надо повернуться в нужную сторону. Подсказка «поверни телефон левее» появляется сама.
- **Значки и диплом** — за каждую точку значок, в конце диплом с именем ребёнка.
- **Тренировка дома** — точка едет по маршруту сама, чтобы проверить всё до выхода.
- **Работает без сети** — после первого захода сайт кэшируется. Кроме тайлов карты, их слишком много.

## Как запустить

Сайт статический, сборка не нужна.

```bash
npx http-server -p 8099 .    # или любой другой статический сервер
```

Открыть `http://localhost:8099`. Для геолокации и камеры браузеру нужен **https** или `localhost` —
по обычному http с телефона камера не включится.

### GitHub Pages

Settings → Pages → Source: Deploy from a branch → ветка `claude/interactive-route-ar-site-bmvlvc`, папка `/ (root)`.
Через минуту сайт будет на `https://crucian1812-a11y.github.io/MAP/` — там https, значит камера и геолокация работают.
Ссылку удобно повесить на домашний экран телефона: сайт открывается как приложение, без адресной строки.

## Перед прогулкой

1. Открыть сайт дома, разрешить геолокацию и камеру — на улице не придётся возиться.
2. В настройках (☰) вписать имя ребёнка для диплома.
3. Там же запустить «Тренировку дома»: точка проедет по маршруту, истории откроются по очереди. Потом нажать «Сбросить прогресс».
4. Проверить AR: нажать в любой истории «Включить дополненную реальность». Дома компас покажет объект прямо перед собой.

## Координаты и калибровка

Координаты точек и линия маршрута выставлены вручную по карте, без геокодера.
Метка может оказаться в двадцати-тридцати метрах от нужного дома. Если заметите — чините на месте:

Настройки → «Калибровка точек» → включить → перетащить метку на карте.
Новые координаты появятся текстом внизу настроек и в консоли браузера. Вставить их в `js/data.js`, в поле `coords`.

Линия маршрута лежит там же, в `ROUTE_PATH` — это просто список координат по улицам.

Leaflet подключается с unpkg, тайлы — OpenStreetMap. Больше зависимостей нет.

## Как устроена AR

Никаких библиотек и маркеров. Работает так: браузер даёт компас (`deviceorientation`) — куда смотрит телефон.
Мы считаем азимут от нашей позиции на объект и разницу углов. Разница переводится в сдвиг по горизонтали
(поле зрения камеры телефона взято за 62°), наклон телефона — в сдвиг по вертикали, расстояние — в масштаб.
Картинка едет по экрану, будто стоит на своём месте.

Ограничения честные: компас на Android иногда врёт на десятки градусов, помогает «восьмёрка» телефоном в воздухе.
На iPhone доступ к компасу спрашивают по нажатию — поэтому кнопка. Если компаса нет вовсе,
сцена показывается прямо по центру, прогулку это не ломает.
